# Hospital Appointment Website

A responsive Hospital Appointment Booking Website developed using HTML and CSS. The website provides an intuitive interface for patients to explore hospital services, view doctors, and book appointments online.

## Live Demo

https://hospoone.netlify.app/

## Features

* Modern and responsive user interface
* Hospital information section
* Doctor details section
* Appointment booking form
* Clean and user-friendly design
* Mobile-friendly layout
* Fast loading static website

## Technologies Used

* HTML5
* CSS3

## Installation

1. Clone the repository

```bash
git clone https://github.com/ShraddhaYewale/HospitalAppointMent.git
```

2. Navigate to the project folder

```bash
cd HospitalAppointMent
```

3. Open `home.html` in your browser.
